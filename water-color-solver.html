    Water Color Solver

    Water Color is an iOS sort-the-bottles puzzle: bottles hold stacked units of colored liquid, and a pour moves the whole same-colored run on top of one bottle onto another bottle that is empty or shows the same color on top, as much as fits. The goal is to end with every bottle holding a single color.

    This applet takes a starting position and explores every position reachable from it, so it can say whether the game can still be won, how fast, and how unforgiving the path is.

    Getting a board in

    • Ready-made boards include one dealt by the game and several found by searching for high difficulty scores, among them two with tall, eight-unit bottles.
    • Screenshot reads a screenshot of the game: it finds the bottles, samples each unit's color and skips the “+” hint bottle. Check the result in the editor.
    • Type it in uses one word per bottle, top to bottom, one letter per color; ? marks a hidden unit and - an empty bottle.

    Hidden colors

    Some levels hide most units behind question marks. The solver then plans the quickest pours that uncover a new color, using only what is visible, and keeps track of where each unit started so the original position fills in as you go.

    Playing

    Play it gives you the board to play by tapping a bottle and then its target, with pours animated as in the game. You can play on your own, be warned when a pour throws the win away, or see every pour marked as best, slower (with the number of extra pours) or losing.

    The move tree

    The radial view puts the current position in the center with one ring per move. Green positions can still be won, red ones are doomed. Each branch gets a wedge proportional to the number of positions beneath it, and edges thicken with the number of positions downstream. A position reached by several move orders appears once, under the first position the search reached it from. Tap a position to center the tree on it and see the moves that lead there.

    Difficulty

    The score out of 100 combines how narrow the winning path is, how many opening moves already lose, the share of doomed positions, how often the tempting move is wrong, the length of the best solution and how deep the dead ends run. The weights are a first guess: random deals of the game's usual size score about 22 on average and rarely pass 40.
