# affinemess-applets

Everything behind [affinemess.com](https://affinemess.com), served by GitHub Pages at
apps.affinemess.com.

- `<slug>.html` — the applets, one self-contained file each
- `src/` — the website's source: `master.html`, `build_site.py`, `test_site.py`, `build_quora.py`
- `site/` — the website as served (generated from `src/`; don't edit by hand)
- `quora/` — Quora answers hosted on the site
- `papers/` — papers hosted on the site

See `CLAUDE.md` for how changes are made.
